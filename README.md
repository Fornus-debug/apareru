# Fornus — Tokyo Noir Collection

"Tokyo Noir" をコンセプトに掲げる、ハイエンド・モード系アパレルブランドの E-commerce フロントエンド・プロジェクトです。
黒を基調としたミニマルで高級感のあるデザインと、滑らかなUXを追求したシングルページアプリケーション感覚の UI を構築しています。

## 🪐 Concept: Tokyo Noir
東京の夜を想起させる深い黒をベースに、控えめで上品なゴールドのアクセントを配したラグジュアリー・モード。
視覚的な美しさだけでなく、堅牢なスクリプトによる安定した操作性を提供します。

## ✨ Key Features
- **Luxury UI/UX**: ガラスモーフィズム、微細な発光エフェクト、8pxグリッドに基づいた秩序あるレイアウト。
- **Responsive Design**: デスクトップからスマートフォンまで、シームレスに最適化されたフルレスポンシブ対応。
- **Intelligent Navigation**:
    - デスクトップ：機能集約型の右寄せナビゲーション。
    - モバイル：左からスライドする高性能なドロワーメニュー。
- **Interactive Mini-cart**: ページ移動なしでカート内容を確認・操作できるミニカート機能。
- **Favorites System**: 商品カードおよび詳細ページから連動するお気に入り機能。`localStorage` により状態を永続化。
- **Robust JavaScript**: Null 安全性の確保、連打防止（Intelligent Lock）、画像の無限ループ防止など、実稼働を想定した堅牢なコード設計。
- **Multilingual Ready**: UI の全英語化によるブランドイメージの統一。

## 🛠 Tech Stack
- **HTML5**: セマンティックなマークアップ。
- **Vanilla CSS3**: 外部ライブラリ（TailwindCSS 等）に頼らない、柔軟かつ高度なスタイリング。
- **Vanilla JavaScript**: フレームワーク（React/Vue 等）を使用せず、ピュアな JS のみで高度な排他制御と状態管理を実現。

## 🚀 Getting Started
特別なビルドステップは必要ありません。
`index.html` をブラウザで開くだけで、Fornus の世界観を体験いただけます。
